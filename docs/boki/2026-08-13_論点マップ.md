### 1.4 【要判断】2027年度改定の影響 — 手形が3級から消滅する

2027年度版の改定趣旨（[PDF](https://www.kentei.ne.jp/wp/wp-content/uploads/2014/10/2027_kaitei_shushi_fixed.pdf)）から確認した事実:

- 背景: 政府方針を受け、全国銀行協会が2025年3月に、**2026年度末をもって電子交換所における手形・小切手の交換を廃止**することを決定。
- 対応: 「紙媒体の手形が廃止されたため、**手形関連の規定はすべて削除**した」。区分表の「5.手形」「6.債権の譲渡」が削除され、「3.売掛金および買掛金ならびに電子記録債権等」に再編される。
- 2027年度の許容勘定科目表を確認したところ、**受取手形・支払手形・手形貸付金・手形借入金・営業外受取手形などの手形系科目は3級2級ともに全て消えている**（本資料作成時に2027年度版PDFを機械抽出して確認）。
- 3級の出題内容が減るため、2級の一部論点を3級へ移行:
  - 販売のつど売上原価勘定に振り替える方法（2級→3級）
  - 有形固定資産の除却・廃棄（2級→3級）
  - 定率法による減価償却（2級→3級。ただし「※」付きで、償却率を示す簡易な出題に留め、200%定率法の保証率・改訂償却率は3級では出題しない）
  - 「普通預金」を区分表に明記（当座預金に先立って記載）
  - 営業外電子記録債権・営業外電子記録債務を区分表に明記
- 3級とリースの関係: 「3級ではリースは出題範囲ではない」。事務所・店舗の賃借は従来どおり支払家賃・支払地代で処理する（2級以上では支払リース料に統一される点と対比）。

**作問への含意（要判断事項）**:
- 2026年度中の運用が前提なら、手形論点は出題可能かつ頻出。
- ただし、この40問プールを2027年4月以降も使い回す予定があるなら、**手形を扱う問題は全て陳腐化する**。手形問題を「差し替え前提の別グループ」に分けてタグ付けしておくか、最初から手形を外して電子記録債権に寄せるかを、発注側で決める必要がある。

## 3. 定番ひっかけパターン集

形式: **正解の処理 → どういう誤解をした人がどの誤答を選ぶか**。4択の誤答選択肢（distractor）はここから機械的に作れる。

### ① 商品売買・仕訳の基礎

| 正解の処理 | 誤解の中身 | その人が選ぶ誤答 |
|---|---|---|
| 当社負担の仕入諸掛は仕入勘定に含める | 「運賃は費用だから別勘定」 | 仕入と発送費（または支払運賃）に分けて計上した選択肢 |
| 先方負担の仕入諸掛を立替払い→立替金（または買掛金の減額） | 負担者を読み飛ばす | 仕入に含めた選択肢 |
| 当社負担の売上諸掛は発送費（費用） | 「売上の付随費用だから売上に含める／控除する」 | 売上を諸掛込み・諸掛控除後にした選択肢 |
| 仕入戻し: (借)買掛金 /(貸)仕入 | 返品の向きが分からない | 貸借を逆にした (借)仕入 /(貸)買掛金 |
| 売上戻り: (借)売上 /(貸)売掛金 | 同上 | 貸借を逆にした選択肢 |
| クレジット売上: 販売時に支払手数料を計上し、クレジット売掛金は手数料控除後 | 「手数料は入金時に払うから入金時計上」 | クレジット売掛金を売価総額で計上し、入金時に手数料を計上した選択肢 |
| 同上 | 「手数料は売上のマイナス」 | 売上を手数料控除後の純額にした選択肢 |
| 税抜方式の仕入: (借)仕入・仮払消費税 /(貸)買掛金 | 税込方式と混同 | 仕入を税込額で計上し仮払消費税がない選択肢 |
| 商品有高帳は原価で記入 | 「売った金額を書く」 | 払出欄に売価を記入した選択肢 |
| 移動平均法は受入のつど加重平均 | 単純平均で計算 | (旧単価＋新単価)÷2 で出した平均単価の選択肢 |
| 先入先出法は残高欄を単価別に複数行で管理 | 1本にまとめる | 残高を平均単価1行にした選択肢（＝移動平均法の答え） |
| 受取商品券の受取は資産計上 | 現金と同一視 | 現金で処理した選択肢 |

### ② 現金・預金

| 正解の処理 | 誤解の中身 | その人が選ぶ誤答 |
|---|---|---|
| 他人振出小切手・送金小切手・郵便為替証書・配当金領収証・期日到来公社債利札は「現金」 | 「小切手＝当座預金」と反射的に結びつける | 当座預金で処理した選択肢 |
| **自己振出**小切手を回収したときは当座預金の増加 | 上と逆に「小切手を受け取った＝現金」と覚える | 現金で処理した選択肢 |
| 現金過不足（実際有高＞帳簿残高）: (借)現金 /(貸)現金過不足 | 過剰と不足の向きを取り違える | 貸借を逆にした選択肢 |
| 決算日に原因不明の不足額 → 雑損 | 「雑費」で処理すると思っている | 雑費を使った選択肢 |
| 決算日に原因不明の過剰額 → 雑益 | 現金過不足を残す | 現金過不足勘定を貸借対照表に残した選択肢 |
| 当座預金が貸方残高（当座借越）→ 決算で当座借越（または借入金）へ振替 | 「マイナスの当座預金」として資産のマイナス表示 | 振替をしない選択肢 |
| 同上 | 借越額の翌期首の再振替を忘れる | 再振替をしない選択肢 |
| 複数口座では口座別の勘定（当座預金○○銀行 等）を使う | 全部まとめて当座預金 | 口座名なしの当座預金にした選択肢 |
| 定額資金前渡法: 報告時に費用計上、補給時に小口現金を補充 | 報告と補給を同時に切ってしまう | 報告時に (借)各費用 /(貸)当座預金 とした選択肢（小口現金勘定が動かない） |
| 会計期末＝補給前のとき、小口現金勘定は使用済み分だけ減っている | 常に定額に戻っていると思い込む | 小口現金を定額で計上した選択肢 |

### ③ 債権債務・手形・電子記録債権

| 正解の処理 | 誤解の中身 | その人が選ぶ誤答 |
|---|---|---|
| 差額補充法: 繰入額＝見積額−期末の貸倒引当金残高 | 洗替法と混同／残高の存在を見落とす | 見積額そのものを繰入額にした選択肢 |
| 見積額＜引当金残高 → 貸倒引当金戻入 | 「繰入をマイナスで書く」 | 貸倒引当金繰入をマイナス表示した選択肢 |
| **当期に発生した**売掛金の貸倒れ → 全額 貸倒損失 | 「引当金があるからまず取り崩す」 | 貸倒引当金を充当した選択肢 |
| **前期以前に発生した**売掛金の貸倒れ → 引当金を充当、不足分のみ貸倒損失 | 全額を貸倒損失にする | 引当金を使わない選択肢 |
| 前期に貸倒処理した債権を当期に回収 → 償却債権取立益 | 「引当金を戻す」 | 貸倒引当金戻入にした選択肢 |
| 同上 | 「売掛金が復活する」 | 売掛金を貸方に立てた選択肢 |
| 商品注文時の内金支払 → 前払金（資産） | 前払費用と混同 | 前払費用を使った選択肢 |
| 同上 | 「支払ったから仕入」 | 仕入を計上した選択肢（＝商品未受取なのに費用計上） |
| 内金受取 → 前受金（負債） | 前受収益と混同／「入金＝売上」 | 前受収益または売上を使った選択肢 |
| 商品以外の物品売買の未収 → 未収入金 | 「売ったから売掛金」 | 売掛金を使った選択肢 |
| 従業員負担分の保険料を会社が立替 → 立替金 | 預り金と混同 | 預り金を使った選択肢 |
| 給与から源泉徴収した所得税 → 所得税預り金 | 立替金と混同 | 立替金を使った選択肢 |
| 出張時の旅費概算払 → 仮払金 | 「使う目的が分かっているから旅費」 | 旅費交通費を即時計上した選択肢 |
| 内容不明の入金 → 仮受金 | 「入金＝売掛金の回収だろう」 | 売掛金を減らした選択肢 |
| 金銭貸借に伴い手形を受け取った → 手形貸付金 | 「手形＝受取手形」 | 受取手形を使った選択肢 |
| 金銭借入に伴い手形を振り出した → 手形借入金 | 同上 | 支払手形を使った選択肢 |
| 電子記録債権の発生記録（売掛金の転化） | 「新しい債権だから売上を立てる」 | 売上を計上した選択肢 |
| 同上 | 手形と同一視 | 受取手形を使った選択肢 |
| 店舗賃借時の敷金 → 差入保証金（資産） | 「家賃の一部」 | 支払家賃で費用処理した選択肢 |

### ④ 固定資産

| 正解の処理 | 誤解の中身 | その人が選ぶ誤答 |
|---|---|---|
| 引取運賃・据付費・仲介手数料・登記費用は取得原価に算入 | 「手数料は費用」 | 支払手数料・租税公課を別計上した選択肢 |
| 取得後の固定資産税は租税公課（費用） | 「固定資産にかかる支出だから取得原価」 | 建物等に加算した選択肢 |
| 期中取得は取得月〜決算月の月割償却 | 「決算だから1年分」 | 年額をそのまま計上した選択肢 |
| 同上 | 月数の起点／終点を1か月ずらす | 1か月多い／少ない金額の選択肢 |
| 期中売却は期首〜売却月の減価償却費を計上してから売却損益を算定 | 償却を飛ばす | 期首簿価と売価の差額を売却損益にした選択肢 |
| 間接法では売却時に減価償却累計額を借方で消す | 直接法と混同 | 建物・備品を簿価で直接減らした選択肢 |
| 減価償却費と減価償却累計額は別勘定 | 混同 | 累計額を費用に、費用を累計額にした選択肢 |
| 3級は定額法・間接法のみ | 2級論点の持ち込み | 定率法で計算した選択肢（＝そもそも出題しない） |

### ⑤ 給与・税金・純資産

| 正解の処理 | 誤解の中身 | その人が選ぶ誤答 |
|---|---|---|
| 給料は総額を計上し、預り金と手取額に分ける | 「払った額が費用」 | 給料を手取額で計上した選択肢 |
| 会社負担の社会保険料 → 法定福利費 | 全額を法定福利費にする | 従業員負担分も法定福利費にした選択肢 |
| 源泉所得税の納付 → 預り金の減少 | 「税金を払った＝租税公課」 | 租税公課を使った選択肢 |
| 収入印紙の購入 → 租税公課、郵便切手 → 通信費 | 両方を消耗品費にする | 消耗品費を使った選択肢 |
| 決算日の未使用分 → 貯蔵品へ振替 | 振替を忘れる／方向を逆にする | 振替をしない、または (借)租税公課 /(貸)貯蔵品 とした選択肢 |
| 中間納付 → 仮払法人税等 | 「税金だから費用」 | 法人税等を即時計上した選択肢 |
| 決算: 法人税等を計上し、仮払法人税等を消して差額を未払法人税等 | 仮払の存在を忘れる | 年税額全額を未払法人税等にした選択肢 |
| 決算: 仮受消費税−仮払消費税＝未払消費税 | 「差額は税金費用」 | 租税公課を使った選択肢 |
| 3級の増資は払込金額の全額を資本金 | 2級の会社法論点を持ち込む | 半額を資本準備金にした選択肢 |
| 配当決議日: (借)繰越利益剰余金 /(貸)未払配当金・利益準備金 | 「配当は資本金から」 | 資本金を減らした選択肢 |
| 同上 | 「支払ったときに剰余金が減る」 | 決議日に仕訳なし、支払日に繰越利益剰余金を減らした選択肢 |
| 利益準備金の積立を忘れない | 配当額しか見ない | 未払配当金のみで利益準備金がない選択肢 |

### ⑥ 決算整理

**最大の誤答源: 経過勘定4分類の混同。** 4択では以下の取り違えをそのまま誤答にできる。

| 状況 | 正解 | 混同されやすい相手 |
|---|---|---|
| 費用を支払済み、当期分でない | 前払費用（資産） | 未払費用 / 前受収益 |
| 収益を受取済み、当期分でない | 前受収益（負債） | 未収収益 / 前払費用 |
| 費用が当期発生、未払 | 未払費用（負債） | 前払費用 / 未収収益 |
| 収益が当期発生、未収 | 未収収益（資産） | 前受収益 / 未払費用 |

| 正解の処理 | 誤解の中身 | その人が選ぶ誤答 |
|---|---|---|
| 売上原価の算定: (借)仕入 /(貸)繰越商品（期首）、(借)繰越商品 /(貸)仕入（期末） | 「しくりくりし」の向きを逆に覚える | 期首と期末を入れ替えた選択肢 |
| 同上 | 期首・期末どちらか一方しか書かない | 片方だけの選択肢 |
| 保険料の前払: (借)前払保険料 /(貸)保険料 | 貸借を逆に | (借)保険料 /(貸)前払保険料（＝再振替仕訳の形） |
| 「毎年○月に向こう1年分を支払」型 | 当期分と次期分の月数を取り違える | 月数が1〜数か月ずれた金額の選択肢 |
| 翌期首に再振替仕訳を行う | 再振替を知らない | 「仕訳なし」の選択肢 |
| 同上 | 決算整理仕訳と同じ向きで書く | 二重計上になる選択肢 |
| 貯蔵品の翌期首再振替 → (借)租税公課 /(貸)貯蔵品 | 向きを逆 | 決算整理と同じ向きの選択肢 |
| 精算表: 当期純利益は損益計算書欄の借方・貸借対照表欄の貸方 | 位置を逆に覚える | 損益計算書欄の貸方に書いた選択肢 |
| 精算表: 修正記入は残高試算表欄の同じ側なら加算、反対側なら減算 | 一律加算する | 加減を取り違えた金額の選択肢 |
| 3級の財務諸表は勘定式 | 報告式（2級）と混同 | 報告式レイアウトの選択肢 |
| 貸借対照表では「貸倒引当金」「減価償却累計額」を控除形式で示す | 負債に計上する | 負債の部に載せた選択肢 |

### ⑦ 帳簿・証ひょう・試算表

| 正解の処理 | 誤解の中身 | その人が選ぶ誤答 |
|---|---|---|
| 1つの取引が複数の補助簿に記入される（例: 商品の掛仕入 → 仕入帳・買掛金元帳・商品有高帳） | 「補助簿は1つ」 | 1つしか選んでいない選択肢 |
| 現金が動かない取引では現金出納帳に記入しない | 「取引があれば現金出納帳」 | 現金出納帳を含めた選択肢 |
| 掛売上の回収が当座振込なら当座預金出納帳・売掛金元帳 | 売上帳も記入すると思う | 売上帳を含めた選択肢（売上帳は売上計上時のみ） |
| 3伝票制の一部現金取引は「分解する方法」と「いったん全額を掛とする方法」の2通り | 一方しか知らない | もう一方の起票結果を選ぶ |
| 入金伝票の科目欄は「入金の相手科目」 | 現金と書く | 現金を科目欄に書いた選択肢 |
| 出金伝票の科目欄は「出金の相手科目」 | 同上 | 同上 |
| 合計試算表には各勘定の借方合計・貸方合計を記入 | 残高試算表と混同 | 残高だけを記入した選択肢 |
| 残高試算表には各勘定の残高のみ | 同上 | 総額を記入した選択肢 |
| 貸借どちらか片方だけの転記漏れ・金額誤りは試算表で発見できる | 「全ての誤りが発見できる」 | 「二重転記／貸借同額の誤記も発見できる」とする選択肢 |
| 貸借同額の誤記入・転記漏れ・勘定科目の誤りは試算表では発見できない | 同上 | 上と同じ |
| 受け取った請求書 → 仕入（買掛金）／発行した請求書控 → 売上（売掛金） | 立場を取り違える | 借方貸方を入れ替えた選択肢 |
| 当座勘定照合表の入金欄は当座預金の増加 | 銀行側の貸借と自社側を混同 | 増減を逆にした選択肢 |

### 4.2 3級の標準勘定科目（A欄）

出典: [商業簿記標準・許容勘定科目表（2〜3級）2022年度版](https://www.kentei.ne.jp/wp/wp-content/uploads/2021/12/2022_kamoku.pdf)（著作権: 日本商工会議所）。以下は同表の3級A欄（標準的な勘定科目）を作問の参照用に区分別に整理したもの。B欄（採点上許容される科目）は §4.5 に要点のみ記す。

**資産**

**負債**
支払手形／買掛金／電子記録債務／前受金／借入金／役員借入金／手形借入金／当座借越／未払金／仮受金／未払利息など未払費用の各勘定／前受地代など前受収益の各勘定／預り金／従業員預り金／所得税預り金／住民税預り金／社会保険料預り金／仮受消費税／未払消費税／未払法人税等／未払配当金

**純資産（資本）**
資本金／利益準備金／繰越利益剰余金

**収益**
売上／受取家賃／受取地代／受取手数料／受取利息／雑益／貸倒引当金戻入／償却債権取立益／固定資産売却益

**費用**
仕入／売上原価／発送費／給料／法定福利費／広告宣伝費／支払手数料／支払利息／旅費交通費／貸倒引当金繰入／貸倒損失／減価償却費／通信費／消耗品費／水道光熱費／支払家賃／支払地代／保険料／租税公課／修繕費／雑費／雑損／固定資産売却損／保管費／諸会費／法人税、住民税及び事業税

**その他**
現金過不足／損益

補足: 「売上原価」が3級A欄にあるため、決算整理で売上原価を仕入勘定ではなく売上原価勘定で算定させる出題は3級で可能。ただし「販売のつど売上原価勘定に振り替える方法」は別論点であり2級（2026年度時点）。

### 4.4 グレーゾーン（区分表に明記がない論点）

区分表に明示がなく、3級で出題してよいか判断が要るもの。**作問では原則として避けるか、問題文で処理方法を明示的に指示する。**

| 論点 | 判定と理由 |
|---|---|
| 5伝票制（売上伝票・仕入伝票） | **避ける。** 区分表 第一 5.イ は「伝票(入金、出金、振替の各伝票)」と3伝票制のみを明記しており、5伝票制の記載がない |
| 資本的支出／収益的支出の区別 | **避けるか指示付きで。** 区分表に明記なし。勘定科目表には修繕費があるため修繕費そのものは可 |
| 備忘価額1円（耐用年数到来後の処理） | **避ける。** 区分表に明記なし |
| 先日付小切手の処理 | **避ける。** 区分表に明記なし |
| 訂正仕訳 | **指示付きなら可。** 区分表に明記はないが、仕訳・転記の基本原理（第一 3）の範囲内で扱える。問題文で誤処理の内容を明示すること |
| 商品券の未使用・失効 | **避ける。** 受取商品券は3級だが、失効処理は明記なし |

### 4.5 許容勘定科目（B欄）— 誤答選択肢設計への影響

勘定科目表は、A欄の標準科目に対しB欄の科目も採点上許容するとしている。**A欄とB欄の違いを正誤の分かれ目にする4択は作ってはいけない。** 3級で許容されている主な組み合わせ:

- 貸倒引当金繰入 ← 貸倒引当金繰入額
- 減価償却費 ← 建物減価償却費、備品減価償却費
- 建物減価償却累計額／備品減価償却累計額 ← 減価償却累計額
- 支払家賃・支払地代 ← 地代家賃、(支払)賃借料、(支払)不動産賃借料
- 保険料 ← 支払保険料、火災保険料
- 租税公課 ← 公租公課、固定資産税、印紙税
- 発送費 ← 支払運賃、発送運賃
- 給料 ← 給料手当、賃金給料
- 法定福利費 ← 社会保険料
- 通信費／消耗品費 ← 事務用消耗品費、水道光熱費 ← 光熱水費
- 普通預金・定期預金 ← 銀行預金
- 前払金 ← 前渡金、未収入金 ← 未収金
- 手形貸付金・従業員貸付金・役員貸付金 ← 貸付金、手形借入金・役員借入金・当座借越 ← 借入金
- 各種預り金 ← 預り金、仮払消費税・仮払法人税等 ← 仮払金、仮受消費税 ← 仮受金、未払消費税 ← 未払金
- 固定資産売却益／損 ← 備品売却益(損)、建物売却益(損)、土地売却益(損)
- 雑益 ← 雑収入、雑収益、雑損 ← 雑損失
- 法人税、住民税及び事業税 ← 法人税等
- 売掛金・買掛金 ← ○○商店（人名勘定）

**実務的な帰結**: 4択の選択肢は「勘定科目名の言い換え」ではなく、**貸借の向き・使う勘定の種類・金額の計算方法**で差をつけること。

## 5. 40問プールの配分案（提案）

配点の二次情報（第1問45点＝仕訳中心、第2問20点＝帳簿・勘定記入、第3問35点＝決算）を参考に、実試験の重心を反映した配分案。発注側で調整可。

| 単元 | 問数 | 根拠 |
|---|---|---|
| ① 商品売買・仕訳の基礎 | 7 | 第1問の主戦場。諸掛・返品・消費税・商品有高帳 |
| ② 現金・預金 | 5 | 現金の範囲・過不足・当座借越・小口現金 |
| ③ 債権債務・手形・電子記録債権 | 7 | 経過勘定と並ぶ誤答多発領域。貸倒引当金を含む |
| ④ 固定資産 | 4 | 取得原価・月割償却・期中売却 |
| ⑤ 給与・税金・純資産 | 5 | 源泉徴収・租税公課・消費税・配当 |
| ⑥ 決算整理 | 8 | 第3問35点相当。経過勘定4分類を厚めに |
| ⑦ 帳簿・証ひょう・試算表 | 4 | 補助簿選択・伝票・試算表 |
| 合計 | 40 | |

作問時の共通ルール（推奨）:
1. 誤答3つは §3 のパターン表から選ぶ。ランダムな数値違いは1問あたり最大1つまで。
2. 「向きの誤り」「範囲の誤り（2級論点の持ち込み）」「金額計算の誤り」を各問で混ぜ、同種の誤答で3つを埋めない。
3. §4.5 のとおり、許容勘定科目の言い換えを不正解にしない。
4. 手形を扱う問題には 2027年度改定で失効する旨のタグを付ける（§1.4）。
