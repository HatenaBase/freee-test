## 実行方法と挙動

- GASエディタで `createManualSheet` を選んで実行する
- 「使い方」シートが無ければ先頭（左端）に挿入。既にあれば `clear()`＋結合解除＋バンディング・条件付き書式の除去をしてから先頭へ移動し、作り直す。他のシートには書き込まない（`setActiveSheet` で表示が「使い方」に切り替わるだけ）
- 完了時は `Logger.log` に出し、`getUi().alert` は try/catch で囲んだ（エディタ実行では getUi が使えないため）
- 本文のうち Code.gs の定数（`DEFAULT_MAX_ATTEMPTS`、`SKILL_CHECK_TOKEN_SHEET`、`SKILL_CHECK_RESULT_SHEET`、`MAIL_TEMPLATE_SHEET`、`MAIL_KEY_FROM`、`MAIL_KEY_SENDER_NAME`、`DEFAULT_MAIL_SENDER_NAME`、`MAIL_LIST_PREVIEW_LIMIT`）は実行時に参照するので、定数を変えれば再実行で追従する。index.html 側の値（合格ライン75%・50問・38問、24時間、レベル境界80/60）はGASから読めないため文字列で固定

### 判断メモ

- README の「確認ダイアログで「OK」」はコード上 `YES_NO` なので、説明書では「はい」と書いた（README 側の表記ずれ。今回は直していない）
- README の「boki/questions.json は開発用ダミー14問」は古い記述。実ファイルは40問（コミット fca576e で本番40問投入）なので「40問から20問」と書いた
- 20260916 作業ログの「タイムゾーンを東京に変えれば保存済みの値はまとめて正しい表示になる」は、スプレッドシートの日時セルがタイムゾーンを持たない値として保存される仕様を踏まえると成り立たない可能性が高い（推定・未検証）。説明書には「GMT設定のため9時間前で表示される」事実だけを書き、設定変更の手順は書いていない
- 「送信元アドレスは実行者のGmailから送られる」「MAIAアドレスは未登録」のうち、後者は時点情報なので説明書には書かず、登録方法だけを書いた
